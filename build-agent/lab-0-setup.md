# Lab 0 · Setup and a Parallel Start

*Goal: kick off the slow thing first, then use the wait to get real work done.*

One piece of this lab takes a few minutes to install, and your backlog cannot load until it finishes. Rather than watch a progress bar, you will start the install and then work in a second browser tab while it completes.

## Step 1 · Start the plugin install

Install `[PLUGIN NAME — confirm on the day]`. This is the one slow step of the morning, and it runs in the background once you start it. Your backlog lab (Lab 3) depends on this being done, so start it now.

## Step 2 · Open a second tab and get building

In the new tab, open ServiceNow Studio and the Build Agent chat. You will scaffold the app (Lab 1), then build the catalog front door (Lab 2), both while the plugin keeps installing in tab one. By the time you reach Lab 3, the install should be complete. Check tab one before starting the backlog lab.
